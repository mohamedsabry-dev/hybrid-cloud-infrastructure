================================================================================
FreeIPA Manual Commands Guide
================================================================================

This guide contains all manual CLI equivalents for the automated IPA playbooks.
Use these commands when you need to manually configure or troubleshoot FreeIPA.

PREREQUISITE: All commands require Kerberos authentication
  kinit admin
  (Enter IPA admin password when prompted)

================================================================================
PHASE 1: IDENTITY STRUCTURE (Users & Groups)
================================================================================
Source: ipa-01-create-users-groups.yml

--------------------------------------------------------------------------------
TASK A: Create Groups
--------------------------------------------------------------------------------

Create users group:
  ipa group-add users --desc="Standard K8s Login Users"

Create operators group:
  ipa group-add operators --desc="K8s Operators (Restricted Sudo)"

Create monitors group:
  ipa group-add monitors --desc="Monitoring Service Accounts"

Create k8s_admins group:
  ipa group-add k8s_admins --desc="Full K8s Cluster Admins"

Create ansible_admins group:
  ipa group-add ansible_admins --desc="Ansible Controller Admins"

Create super_users group:
  ipa group-add super_users --desc="Admins with super privilages"

Create backup_users group:
  ipa group-add backup_users --desc="Backup Administrators"

--------------------------------------------------------------------------------
TASK B: Create Users
--------------------------------------------------------------------------------

Manual equivalent (example for one user):
  ipa user-add user1 --first=User --last=One --password
  (Then enter password when prompted)

To create all users manually:
  for user in user1 user2 user3 operator1...; do
    ipa user-add $user --first=FirstName --last=LastName --password
  done

Individual user creation commands:
  ipa user-add user1 --first=User --last=One --password
  ipa user-add user2 --first=User --last=Two --password
  ipa user-add user3 --first=User --last=Three --password
  ipa user-add operator1 --first=Op --last=One --password
  ipa user-add operator2 --first=Op --last=Two --password
  ipa user-add operator3 --first=Op --last=Three --password
  ipa user-add operator4 --first=Op --last=Four --password
  ipa user-add monitor1 --first=Mon --last=One --password
  ipa user-add monitor2 --first=Mon --last=Two --password
  ipa user-add monitor3 --first=Mon --last=Three --password
  ipa user-add admin1 --first=Admin --last=One --password
  ipa user-add admin2 --first=Admin --last=Two --password
  ipa user-add ansible_admin --first=Ansible --last=Admin --password
  ipa user-add super_ansible --first=super --last=ansible --password
  ipa user-add veeam --first=Backup --last=veeam --password

--------------------------------------------------------------------------------
TASK C: Assign Users to Groups
--------------------------------------------------------------------------------

Add users to users group:
  ipa group-add-member users --users=user1
  ipa group-add-member users --users=user2
  ipa group-add-member users --users=user3

Add users to operators group:
  ipa group-add-member operators --users=operator1
  ipa group-add-member operators --users=operator2
  ipa group-add-member operators --users=operator3
  ipa group-add-member operators --users=operator4

Add users to monitors group:
  ipa group-add-member monitors --users=monitor1
  ipa group-add-member monitors --users=monitor2
  ipa group-add-member monitors --users=monitor3

Add users to k8s_admins group:
  ipa group-add-member k8s_admins --users=admin1
  ipa group-add-member k8s_admins --users=admin2

Add users to ansible_admins group:
  ipa group-add-member ansible_admins --users=ansible_admin

Add users to super_users group:
  ipa group-add-member super_users --users=super_ansible

Add users to backup_users group:
  ipa group-add-member backup_users --users=veeam

To verify membership:
  ipa group-show users
  ipa group-show operators
  ipa group-show k8s_admins
  ipa user-show user1

================================================================================
PHASE 2: HOST ORGANIZATION (Host Groups)
================================================================================
Source: ipa-02-create-hostgroups.yml

--------------------------------------------------------------------------------
TASK 1: Create Host Groups
--------------------------------------------------------------------------------

Create management host group:
  ipa hostgroup-add management --desc="General Infrastructure (Legacy)"

Create k8s host group:
  ipa hostgroup-add k8s --desc="Kubernetes Cluster Nodes"

Create controllers host group:
  ipa hostgroup-add controllers --desc="Ansible Automation Controllers"

Create backup_servers host group:
  ipa hostgroup-add backup_servers --desc="Backup Servers Group"

Create monitors host group:
  ipa hostgroup-add monitors --desc="Monitoring Servers Group"

To list host groups:
  ipa hostgroup-find

--------------------------------------------------------------------------------
TASK 2: Add Ansible VM to controllers group
--------------------------------------------------------------------------------

Add ansible.home.lab to controllers:
  ipa hostgroup-add-member controllers --hosts=ansible.home.lab

To verify:
  ipa hostgroup-show controllers

--------------------------------------------------------------------------------
TASK 3: Add K8s nodes to k8s group
--------------------------------------------------------------------------------

Add K8s nodes to k8s group:
  ipa hostgroup-add-member k8s --hosts=k8s-master.home.lab
  ipa hostgroup-add-member k8s --hosts=k8s-worker1.home.lab
  ipa hostgroup-add-member k8s --hosts=k8s-worker2.home.lab

To verify:
  ipa hostgroup-show k8s

--------------------------------------------------------------------------------
TASK 4: Populate 'management' (Legacy/General Group)
--------------------------------------------------------------------------------

Add hosts to management group:
  ipa hostgroup-add-member management --hosts=ipa.home.lab
  ipa hostgroup-add-member management --hosts=ansible.home.lab

To verify:
  ipa hostgroup-show management

--------------------------------------------------------------------------------
TASK 5: Add All Nodes to Backup Servers Group
--------------------------------------------------------------------------------

Add all hosts to backup_servers group:
  ipa hostgroup-add-member backup_servers --hosts=ipa.home.lab
  ipa hostgroup-add-member backup_servers --hosts=ansible.home.lab
  ipa hostgroup-add-member backup_servers --hosts=k8s-master.home.lab
  ipa hostgroup-add-member backup_servers --hosts=k8s-worker1.home.lab
  ipa hostgroup-add-member backup_servers --hosts=k8s-worker2.home.lab
  ipa hostgroup-add-member backup_servers --hosts=monitor.home.lab

To verify:
  ipa hostgroup-show backup_servers

--------------------------------------------------------------------------------
TASK 6: Add Monitor Server to Monitors Group
--------------------------------------------------------------------------------

Add monitor server to monitors group:
  ipa hostgroup-add-member monitors --hosts=monitor.home.lab

To verify:
  ipa hostgroup-show monitors

PHASE 2B: ACCESS CONTROL (HBAC Rules)
================================================================================
Source: ipa-03-configure-hbac-rules.yml

--------------------------------------------------------------------------------
Rule 1: K8s Access Control
--------------------------------------------------------------------------------

Create and configure allow_k8s_ssh rule:
  ipa hbacrule-add allow_k8s_ssh --desc="Allow Standard, Ops, and admin SSH to K8s"
  ipa hbacrule-add-user allow_k8s_ssh --groups=users
  ipa hbacrule-add-user allow_k8s_ssh --groups=operators
  ipa hbacrule-add-user allow_k8s_ssh --groups=k8s_admins
  ipa hbacrule-add-host allow_k8s_ssh --hostgroups=k8s
  ipa hbacrule-add-service allow_k8s_ssh --hbacsvcs=sshd

To verify:
  ipa hbacrule-show allow_k8s_ssh

To test access:
  ipa hbactest --user=user1 --host=k8s-master.home.lab --service=sshd

--------------------------------------------------------------------------------
Rule 2: Controller Access Control
--------------------------------------------------------------------------------

Create and configure allow_controller_ssh rule:
  ipa hbacrule-add allow_controller_ssh --desc="Allow Ansible Admins to SSH into Controllers"
  ipa hbacrule-add-user allow_controller_ssh --groups=ansible_admins
  ipa hbacrule-add-host allow_controller_ssh --hostgroups=controllers
  ipa hbacrule-add-service allow_controller_ssh --hbacsvcs=sshd

To verify:
  ipa hbacrule-show allow_controller_ssh

To test access:
  ipa hbactest --user=ansible_admin --host=ansible.home.lab --service=sshd

--------------------------------------------------------------------------------
Rule 3: Automation Superuser Access (Unrestricted)
--------------------------------------------------------------------------------

Create and configure allow_automation_ssh rule:
  ipa hbacrule-add allow_automation_ssh --desc="Allow Super Ansible to SSH everywhere"
  ipa hbacrule-add-user allow_automation_ssh --groups=super_users
  ipa hbacrule-add-host allow_automation_ssh --hostgroups=k8s
  ipa hbacrule-add-host allow_automation_ssh --hostgroups=controllers
  ipa hbacrule-add-host allow_automation_ssh --hostgroups=management
  ipa hbacrule-add-service allow_automation_ssh --hbacsvcs=sshd

To verify:
  ipa hbacrule-show allow_automation_ssh

To test access:
  ipa hbactest --user=super_ansible --host=k8s-master.home.lab --service=sshd

IMPORTANT: This gives super_ansible access to ALL hosts in the infrastructure

--------------------------------------------------------------------------------
Rule 4: Backup Users Access Control
--------------------------------------------------------------------------------

Create and configure allow_backup_ssh rule:
  ipa hbacrule-add allow_backup_ssh --desc="Allow Backup Users to SSH into Backup Servers"
  ipa hbacrule-add-user allow_backup_ssh --groups=backup_users
  ipa hbacrule-add-host allow_backup_ssh --hostgroups=backup_servers
  ipa hbacrule-add-service allow_backup_ssh --hbacsvcs=sshd

To verify:
  ipa hbacrule-show allow_backup_ssh

PHASE 3: PRIVILEGE MANAGEMENT (Sudo Rules)
================================================================================
Source: ipa-04-configure-sudo-rules.yml

--------------------------------------------------------------------------------
SECTION 1: DEFINE SUDO COMMANDS
--------------------------------------------------------------------------------

Create individual sudo commands:
  ipa sudocmd-add "/usr/sbin/ip a"
  ipa sudocmd-add "/usr/sbin/ip route"
  ipa sudocmd-add "/usr/bin/ping"
  ipa sudocmd-add "/usr/sbin/ss -tulpn"
  ipa sudocmd-add "/usr/bin/tail"
  ipa sudocmd-add "/usr/bin/grep"
  ipa sudocmd-add "/usr/bin/less"
  ipa sudocmd-add "/usr/bin/cat /var/log/messages"
  ipa sudocmd-add "/usr/bin/cat /var/log/syslog"

To list all sudo commands:
  ipa sudocmd-find

To show specific command:
  ipa sudocmd-show "/usr/sbin/ip a"

--------------------------------------------------------------------------------
SECTION 2: GROUP COMMANDS
--------------------------------------------------------------------------------

Create ops_network command group:
  ipa sudocmdgroup-add ops_network --desc="Network Troubleshooting Commands"
  ipa sudocmdgroup-add-member ops_network --sudocmds="/usr/sbin/ip a"
  ipa sudocmdgroup-add-member ops_network --sudocmds="/usr/sbin/ip route"
  ipa sudocmdgroup-add-member ops_network --sudocmds="/usr/bin/ping"
  ipa sudocmdgroup-add-member ops_network --sudocmds="/usr/sbin/ss -tulpn"

To verify:
  ipa sudocmdgroup-show ops_network

Create ops_logs command group:
  ipa sudocmdgroup-add ops_logs --desc="Log Reading Commands"
  ipa sudocmdgroup-add-member ops_logs --sudocmds="/usr/bin/tail"
  ipa sudocmdgroup-add-member ops_logs --sudocmds="/usr/bin/grep"
  ipa sudocmdgroup-add-member ops_logs --sudocmds="/usr/bin/less"
  ipa sudocmdgroup-add-member ops_logs --sudocmds="/usr/bin/cat /var/log/messages"
  ipa sudocmdgroup-add-member ops_logs --sudocmds="/usr/bin/cat /var/log/syslog"

To verify:
  ipa sudocmdgroup-show ops_logs

--------------------------------------------------------------------------------
SECTION 3: CREATE SUDO RULES
--------------------------------------------------------------------------------

Rule A - K8s Admins (Full Power on K8s):
  ipa sudorule-add admin_k8s_full --desc="Full Root Access for K8s Admins"
  ipa sudorule-add-user admin_k8s_full --groups=k8s_admins
  ipa sudorule-add-host admin_k8s_full --hostgroups=k8s
  ipa sudorule-mod admin_k8s_full --cmdcat=all

To verify:
  ipa sudorule-show admin_k8s_full

Rule B - Ansible Admins (Full Power on Controllers):
  ipa sudorule-add admin_ansible_full --desc="Full Root Access for Ansible Controllers"
  ipa sudorule-add-user admin_ansible_full --groups=ansible_admins
  ipa sudorule-add-host admin_ansible_full --hostgroups=controllers
  ipa sudorule-mod admin_ansible_full --cmdcat=all

To verify:
  ipa sudorule-show admin_ansible_full

Rule C - Operators (Restricted):
  ipa sudorule-add ops_k8s_restricted --desc="Restricted Network & Log Access"
  ipa sudorule-add-user ops_k8s_restricted --groups=operators
  ipa sudorule-add-host ops_k8s_restricted --hostgroups=k8s
  ipa sudorule-add-host ops_k8s_restricted --hostgroups=controllers
  ipa sudorule-add-allow-cmdgroup ops_k8s_restricted --sudocmdgroups=ops_network
  ipa sudorule-add-allow-cmdgroup ops_k8s_restricted --sudocmdgroups=ops_logs

To verify:
  ipa sudorule-show ops_k8s_restricted

Rule D - Super Automation (Passwordless):
  ipa sudorule-add super_automation_nopass --desc="Unlimited Access for Robots No password"
  ipa sudorule-add-user super_automation_nopass --groups=super_users
  ipa sudorule-add-host super_automation_nopass --hostgroups=k8s
  ipa sudorule-add-host super_automation_nopass --hostgroups=controllers
  ipa sudorule-add-host super_automation_nopass --hostgroups=management
  ipa sudorule-mod super_automation_nopass --cmdcat=all
  ipa sudorule-add-option super_automation_nopass --sudooption='!authenticate'

To verify:
  ipa sudorule-show super_automation_nopass

IMPORTANT: The !authenticate option means no password required for sudo

Rule E - Backup Users (Full):
  ipa sudorule-add backup_users_full --desc="Full Backup Access"
  ipa sudorule-add-user backup_users_full --groups=backup_users
  ipa sudorule-add-host backup_users_full --hostgroups=backup_servers
  ipa sudorule-mod backup_users_full --cmdcat=all

To verify:
  ipa sudorule-show backup_users_full
