  General pattern:
  vault <command> <subcommand> <path> [options]             
                  
  ---
  Main commands:                                            
                                                            
  ┌───────────────┬──────────────────────────┐              
  │    Command    │       What it does       │              
  ├───────────────┼──────────────────────────┤
  │ vault auth    │ manage auth methods      │
  ├───────────────┼──────────────────────────┤
  │ vault secrets │ manage secrets engines   │
  ├───────────────┼──────────────────────────┤
  │ vault policy  │ manage policies          │
  ├───────────────┼──────────────────────────┤              
  │ vault kv      │ interact with KV secrets │
  ├───────────────┼──────────────────────────┤              
  │ vault read    │ read any path            │
  ├───────────────┼──────────────────────────┤
  │ vault write   │ write to any path        │
  ├───────────────┼──────────────────────────┤              
  │ vault list    │ list keys at a path      │
  └───────────────┴──────────────────────────┘              
                  
  ---
  KV specific:
  vault kv put secret/nginx/config key="value"    # write   
  vault kv get secret/nginx/config                # read 
  vault kv list secret/                           # list    
  vault kv delete secret/nginx/config            # delete
  vault kv metadata get secret/nginx/config      # see      
  versions history
                                                            
  ---             
  Everything else uses read/write:                          
  vault write auth/ldap/config url="ldaps://..."  # 
  configure something
  vault read auth/ldap/config                     # read 
  config                                                    
  vault list auth/userpass/users                  # list 
  items                                                     
                  
  ---
  Pattern to remember:
  - kv commands → for your secrets data                     
  - read/write → for everything else (config, auth, policies
   setup)                                                   
  - list → to explore what exists at any path
