Evidence: DB Queries WITH Varnish
=====================================

Setup: Client → Varnish (:80) → Nginx (:8080) → 3x Apache → PHP-FPM → PostgreSQL

Test: 6 curls to http://localhost:80

PostgreSQL log:
  2026-07-13 00:18:27.043 [8598] LOG:  statement: SELECT name, price FROM products
  (only 1 query — the first cache MISS)

Nginx access log:
  127.0.0.1 - - [13/Jul/2026:00:18:27 +0300] "GET / HTTP/1.1" 200 262
  (only 1 request reached Nginx — the other 5 were served by Varnish cache)

Curl output:
  All 6 responses show "Served by: test2.lab.local on port 8082"
  Same port every time — Varnish cached the first response and replayed it.
  No load balancing on cached requests because Nginx was never asked.

Comparison:
  WITHOUT Varnish: 10 requests = 10 DB queries, 10 Nginx forwards
  WITH Varnish:     6 requests = 1 DB query,   1 Nginx forward

Conclusion: Varnish eliminates repeated backend load by serving from memory cache.
