PROXMOX MIGRATION NOTES - Hybrid Cloud Infrastructure
================================================================================
Date: January 2026
Status: Planning Phase

================================================================================
DECISION SUMMARY
================================================================================

Migrating from:
  - VMware Workstation -> ESXi Master -> Nested ESXi (Prod/DR)
  - vCenter (7GB RAM overhead)
  - Veeam Backup (10 VM limit on free version)
  - NAS VM with NFS shares

Migrating to:
  - VMware Workstation -> Proxmox Master -> Nested Proxmox (Prod/DR)
  - Proxmox Backup Server (unlimited VMs, free)
  - TrueNAS SCALE (ZFS storage)

RAM Savings: ~9-10GB (from ~13GB overhead to ~3-4GB)

================================================================================
ARCHITECTURE - NESTED PROXMOX
================================================================================

VMware Workstation (Windows 11 Host)
└── Proxmox Master (~2GB overhead)
    ├── TrueNAS SCALE (8GB) ─── NFS shared storage for nested Proxmox
    ├── pfSense (2GB)
    ├── FreeIPA (2GB)
    ├── Proxmox Backup Server (4GB)
    ├── Proxmox-Prod (~1GB + 25GB for nested VMs) ─ ACTIVE
    │   ├── K8s Master
    │   ├── K8s Workers (3x)
    │   ├── Vault Cluster (3x)
    │   ├── Jenkins
    │   ├── Grafana
    │   └── Ansible
    └── Proxmox-DR (0GB when off, ~26GB when active) ─ COLD STANDBY

Benefits:
  - True isolation between infrastructure and production layers
  - Cold DR concept preserved (power off = 0 RAM usage)
  - ~9GB RAM savings vs ESXi + vCenter
  - Unlimited backup with PBS
  - Fully free and open source

================================================================================
VMWARE WORKSTATION VM SETTINGS (For Proxmox Master)
================================================================================

Guest OS Type:     Debian 12.x 64-bit (or Linux Other 6.x kernel)
RAM:               32GB (adjust based on workload)
CPU:               12+ vCPUs
Disk:              200GB+ thin provisioned
Network:           3 NICs
                   - NIC1: VMnet0 (Bridge) - WAN
                   - NIC2: VMnet2 (Host-Only) - Internal 10.0.20.x/24
                   - NIC3: VMnet3 (Host-Only) - vMotion 10.0.30.x/24

CRITICAL SETTING:
  Processors -> [x] Virtualize Intel VT-x/EPT or AMD-V/RVI
  (Required for nested virtualization)

TERRAFORM FOR PROXMOX
================================================================================

Recommended Provider:
  bpg/proxmox (actively maintained, modern)

  Registry: https://registry.terraform.io/providers/bpg/proxmox/latest

Terraform Version:
  >= 1.5.0 (recommended latest 1.x)

Provider Configuration:
--------------------------------------------------------------------------------
terraform {
  required_version = ">= 1.5.0"

  required_providers {
    proxmox = {
      source  = "bpg/proxmox"
      version = ">= 0.50.0"
    }
  }
}

provider "proxmox" {
  endpoint = "https://proxmox-master.home.lab:8006/"
  username = "root@pam"
  password = var.proxmox_password
  insecure = true  # For self-signed certs in homelab

  ssh {
    agent = true
  }
}
--------------------------------------------------------------------------------

Example VM Resource:
--------------------------------------------------------------------------------
resource "proxmox_virtual_environment_vm" "k8s_worker" {
  name      = "k8s-worker-1"
  node_name = "proxmox-prod"

  clone {
    vm_id = 9000  # Template ID
  }

  cpu {
    cores = 2
    type  = "host"
  }

  memory {
    dedicated = 2304  # 2.25GB in MB
  }

  network_device {
    bridge = "vmbr1"  # Internal network
  }

  disk {
    datastore_id = "local-lvm"
    size         = 50
    interface    = "scsi0"
  }
}

================================================================================
NETWORK MAPPING
================================================================================

Old (VMware/ESXi)          →    New (Proxmox)
---------------------------------------------------------
VMnet0 (Bridge/WAN)        →    vmbr0
VMnet2 (Internal)          →    vmbr1
VMnet3 (vMotion)           →    vmbr2

IP Scheme remains:
  - WAN: 192.x.x.x/24
  - Internal: 10.0.20.x/24
  - vMotion/Migration: 10.0.30.x/24
