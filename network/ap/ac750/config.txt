================================================================================
                         WHY UNIFIED MANAGEMENT VLAN?
================================================================================

Consumer AP Limitation:
─────────────────────────────────────────────────────────────────────────────────
The Archer C24 (consumer AP) cannot pass VLAN tags over 802.11 WiFi.
All WiFi management traffic is untagged → PVID 5 → VLAN 5.

This means:
├── Cannot have separate WiFi VLANs for PROD/DEV management
├── All WiFi clients land on same VLAN 5
└── Must use AP Isolation for security separation

================================================================================
                         AP ISOLATION (SECURITY)
================================================================================

How It Works:
─────────────────────────────────────────────────────────────────────────────────
AP Isolation enabled at Layer 2. Each WiFi client can only reach
the gateway (10.0.5.1), not other clients.

Effect:
├── DEV (10.0.5.110) ←✗→ PROD (10.0.5.100) - BLOCKED
├── Any WiFi client → Gateway (10.0.5.1) - ALLOWED
└── Any WiFi client → Other clients - BLOCKED

Security Model:
├── Proxmox servers on same WiFi VLAN cannot reach each other directly
├── All inter-server traffic must go through ER605 gateway
└── ER605 ACLs control what traffic is allowed between devices

================================================================================
                         PROXMOX WIFI CLIENT CONFIGURATION
================================================================================

WiFi Packages Required:
─────────────────────────────────────────────────────────────────────────────────
```bash
apt update && apt install -y wpasupplicant wireless-tools
```

WPA Supplicant Configuration:
─────────────────────────────────────────────────────────────────────────────────
File: /etc/wpa_supplicant/wpa_supplicant-<interface>.conf

```
ctrl_interface=/var/run/wpa_supplicant
update_config=1
country=US

network={
    ssid="unified_mgmt"
    psk="<password>"
    key_mgmt=WPA-PSK
}
```

chmod 600 /etc/wpa_supplicant/wpa_supplicant-<interface>.conf

Network Interface Configuration:
─────────────────────────────────────────────────────────────────────────────────
In /etc/network/interfaces:

```
# WiFi Management Interface
auto wlp1s0
iface wlp1s0 inet static
    address 10.0.5.110    # DEV: 10.0.5.110, PROD: 10.0.5.100
    netmask 255.255.255.0
    gateway 10.0.5.1
    wpa-conf /etc/wpa_supplicant/wpa_supplicant-wlp1s0.conf
```

Enable Service:
─────────────────────────────────────────────────────────────────────────────────
```bash
systemctl enable wpa_supplicant
```
