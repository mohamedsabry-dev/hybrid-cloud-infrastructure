================================================================================
                         4. DHCP CONFIGURATION
================================================================================

Path: Network > LAN > [Network] > DHCP

DHCP Pattern (all VLANs):
   |- IP Range: 10.0.X.200 - 10.0.X.220
   |- Gateway: 10.0.X.1
   |- Domain: lab.local
   |- DNS: Per environment (see below)

   +-------------+--------+------------------+---------------+
   | Environment | VLANs  | Primary DNS      | Secondary DNS |
   +-------------+--------+------------------+---------------+
   | Dev         | 60-65  | 10.0.60.10 (IPA) | 8.8.8.8       |
   | Prod        | 50-55  | 10.0.50.10 (IPA) | 8.8.8.8       |
   | Management  | 1, 5   | 8.8.8.8          | 1.1.1.1       |
   +-------------+--------+------------------+---------------+

DNS Architecture:
   |- Clients get DNS from DHCP (IPA server IP)
   |- IPA resolves *.lab.local internally
   |- IPA forwards external queries to 8.8.8.8

IPA Forwarder Config:
   ipa dnsconfig-mod --forwarder=8.8.8.8 --forwarder=1.1.1.1
   ipa dnsconfig-show

NOTE: LXC containers inherit DNS from Proxmox host by default.
      Set explicit DNS in LXC config if DHCP DNS is needed.
