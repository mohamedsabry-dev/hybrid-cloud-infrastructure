================================================================================
                         NETWORK TOPOLOGY
================================================================================

COMPONENTS:
  1. ISP Router           - Internet gateway
  2. AX3000 Router        - Main LAN (192.168.0.x)
  3. ER605                - Firewall, VPN, Gateway, Router
  4. FS308GP              - L2 Switch, PoE, ACL
  5. AC750                - Access Point (SSID WiFi)
  6. NAS FS6706T          - ASUSTOR FlashStor Storage
  7. Prod Server          - Asus TUF Gaming A15
  8. Dev Server           - Asus Vivobook 15

================================================================================
                         PHYSICAL TOPOLOGY
================================================================================

ISP
└── AX3000 (192.168.0.x)
    │
    ├── ER605 [WAN Port 1] (192.168.0.175)
    │   ├── Port 2 ─── Internal Managment LAN > Default-Vlan1 "Empty"
    │   ├── Port 3 ─── AC750 AP [VLAN 5 Untagged]
    │   │               ├── NAS Mgmt Port
    │   │               └── WiFi SSID
    │   │                   ├── Prod Server (wlp4s0) - Mgmt
    │   │                   └── Dev Server (wlp1s0) - Mgmt
    │   ├── Port 4 ─── FS308GP Port 2 [Prod SVC Uplink]
    │   └── Port 5 ─── FS308GP Port 3 [Dev SVC Uplink]
    │
    ├── FS308GP [Mgmt Port 1 - LAN] (192.168.0.185)
    │   │
    │   ├── VLAN 40 (Storage) ─ Tagged
    │   │   ├── Port 8 ─── Prod Server (stor0)
    │   │   ├── Port 7 ─── Dev Server (stor0)
    │   │   └── Port 6 ─── NAS (LAN 1)
    │   │
    │   ├── VLAN 50-55 (Prod Services) ─ Tagged
    │   │   └── Port 5 ─── Prod Server (trunk)
    │   │
    │   └── VLAN 60-65 (Dev Services) ─ Tagged
    │       └── Port 4 ─── Dev Server (trunk)
    │
    └── Mac Mini (WiFi)
        └── Static route: 10.0.0.0/16 via 192.168.0.175

================================================================================
                         VLAN SUMMARY

  VLAN 40     │ Storage         │ NAS, Server Storage NICs
  VLAN 50-55  │ Prod Services   │ Production workloads
  VLAN 60-65  │ Dev Services    │ Development workloads
