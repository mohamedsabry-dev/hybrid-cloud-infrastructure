================================================================================
                         NETWORK TOPOLOGY
================================================================================

COMPONENTS:
  1. ISP ONT             - Internet gateway (fiber terminal)
  2. ER605               - Firewall, VPN, Gateway, Router
  3. FS308GP             - L2 Switch, PoE, VLAN switching
  4. AX3000              - Home WiFi Access Point only
  5. AC750               - Lab Management WiFi Access Point
  6. NAS FS6706T         - ASUSTOR FlashStor Storage
  7. Prod Server         - Proxmox Production
  8. Dev Server          - Proxmox Development

================================================================================
                         PHYSICAL TOPOLOGY
================================================================================

ISP ONT
├── ER605 [WAN Port] ─────────────────── Lab Network Gateway
│   │
│   ├── Port 2 ─── Internal Management LAN (Default-Vlan1)
│   │
│   ├── Port 3 ─── AC750 AP [VLAN 5 Untagged]
│   │               ├── NAS Mgmt Port
│   │               └── WiFi SSID: unified_mgmt
│   │                   ├── Prod Server (wlp4s0) - Mgmt
│   │                   └── Dev Server (wlp1s0) - Mgmt
│   │
│   ├── Port 4 ─── FS308GP Port 2 [Prod SVC Uplink]
│   │
│   └── Port 5 ─── FS308GP Port 3 [Dev SVC Uplink]
│
├── FS308GP [Direct to ISP for Festa Cloud management]
│   │
│   ├── VLAN 40 (Storage) ─ Tagged
│   │   ├── Port 8 ─── Prod Server (stor0)
│   │   ├── Port 7 ─── Dev Server (stor0)
│   │   └── Port 6 ─── NAS (LAN 1)
│   │
│   ├── VLAN 50-55 (Prod Services) ─ Tagged
│   │   └── Port 5 ─── Prod Server (trunk)
│   │
│   └── VLAN 60-65 (Dev Services) ─ Tagged
│       └── Port 4 ─── Dev Server (trunk)
│
└── AX3000 [WiFi AP Mode] ─────────────── Home Devices WiFi Only
    └── Home devices (phones, tablets, etc.)

================================================================================
                         TRAFFIC FLOW
================================================================================

Lab Traffic:
└── All lab traffic routes through ER605 for firewall/ACL control

Home Traffic:
└── Home devices on AX3000 WiFi go directly to ISP (isolated from lab)

Storage Traffic:
└── VLAN 40 isolated at L2 level (no ER605 routing)

================================================================================
                         VLAN SUMMARY
================================================================================

  VLAN 5      │ Management      │ ER605 LAN, Lab WiFi Mgmt
  VLAN 40     │ Storage         │ NAS, Server Storage NICs
  VLAN 50-55  │ Prod Services   │ Production workloads
  VLAN 60-65  │ Dev Services    │ Development workloads
