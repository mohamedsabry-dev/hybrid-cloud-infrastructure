================================================================================
                         FS308GP CONFIGURATION GUIDE
================================================================================

Device: Festa FS308GP
Role: L2 Switch, PoE, VLAN Switching
Management IP: 192.168.0.185 (via AX3000)
Controller: Festa Cloud

================================================================================
                         1. INITIAL SETUP (Festa Cloud)
================================================================================

   ├── Connect switch to AX3000 (gets DHCP IP on 192.168.0.x)
   ├── Login to Festa Cloud Controller
   ├── Adopt device using Serial Number (SN)
   └── Assign static management IP after adoption

================================================================================
