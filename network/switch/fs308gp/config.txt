================================================================================
                         FS308GP CONFIGURATION
================================================================================

Device: Festa FS308GP
Role: L2 Switch, PoE, VLAN Switching
Controller: Festa Cloud
Management IP: 192.168.100.185/24 (static)

================================================================================
                         CURRENT STATE
================================================================================

After TS-NET-003, service VLAN trunks were rewired directly from each
Proxmox host to a dedicated MikroTik port (bypassing the switch). The
FS308GP now carries ONLY storage traffic.

   Port  | Profile  | Description
   ------|----------|--------------------------------------------
   Port1 | LAN      | ISP Uplink (Cloud Mgmt)
   Port2 | UNUSED   | (was: Prod SVC uplink to router)
   Port3 | UNUSED   | (was: Dev SVC uplink to router)
   Port4 | UNUSED   | (was: Dev svc0 trunk)
   Port5 | UNUSED   | (was: Prod svc0 trunk)
   Port6 | Storage  | NAS (LAN 1)
   Port7 | Storage  | Dev Server (stor0)
   Port8 | Storage  | Prod Server (stor0)

Active VLANs:
  - VLAN 1  — management interface (192.168.100.185)
  - VLAN 40 — storage (only workload VLAN on this switch)
  - VLAN 99 — native PVID on unused trunk ports

Service VLANs (50-55, 60-65) are still defined on the switch for
consistency but no traffic for them flows through it anymore.

ACL status: not configured. No longer needed on the switch — service
VLAN isolation is enforced at the MikroTik router layer. The only
potential future use is restricting management access to the switch
itself.

================================================================================
                         HISTORICAL DESIGN (REFERENCE)
================================================================================

The sections below describe the switch when service VLAN trunks ran
through it. No longer deployed — kept as reference.

PORT ASSIGNMENTS (ORIGINAL)
-------------------------------------------------------------------------------

   Port  | Profile      | Description                    | PoE | LoopDet
   ------|--------------|--------------------------------|-----|--------
   Port1 | LAN          | ISP Uplink (Cloud Mgmt)        | On  | Yes
   Port2 | Prod_SVC_All | Prod Uplink (to router)        | Off | No
   Port3 | Dev_SVC_All  | Dev Uplink (to router)         | Off | No
   Port4 | Dev_SVC_All  | Dev Server Trunk (svc0)        | Off | No
   Port5 | Prod_SVC_All | Prod Server Trunk (svc0)       | On  | No
   Port6 | Storage      | NAS (LAN 1)                    | On  | Yes
   Port7 | Storage      | Dev Server (stor0)             | On  | Yes
   Port8 | Storage      | Prod Server (stor0)            | On  | Yes

PORT PROFILES
-------------------------------------------------------------------------------

   Profile      | Native (PVID) | Tagged VLANs
   -------------|---------------|----------------------------
   LAN          | VLAN 1        | -
   DUMP_VLAN    | VLAN 99       | -
   Storage      | VLAN 99       | 40
   Prod_SVC_All | VLAN 99       | 50,51,52,53,54,55
   Dev_SVC_All  | VLAN 99       | 60,61,62,63,64,65

   PVID 99 (DUMP_VLAN) used as native for all trunk ports.

CLI REFERENCE (for the historical trunk ports)
-------------------------------------------------------------------------------

   # Example Trunk Port (Prod)
   interface gigabitEthernet 1/0/2
     switchport general allowed vlan 99 untagged
     switchport general allowed vlan 50-55 tagged
     switchport pvid 99

   # Example Storage Port
   interface gigabitEthernet 1/0/6
     switchport general allowed vlan 99 untagged
     switchport general allowed vlan 40 tagged
     switchport pvid 99
     loopback-detection config process-mode port-based recovery-mode auto
