================================================================================
                         NETWORK TOPOLOGY
================================================================================

COMPONENTS:
  1. ISP ONT                 - Internet gateway (fiber terminal)
  2. MikroTik L009UiGS-RM    - Firewall, VPN, Gateway, Router
                               (replaced a TP-Link ER605 — see network/README.md)
  3. FS308GP                 - L2 Switch, PoE, VLAN switching (storage only now)
  4. AX3000                  - Home WiFi Access Point (home devices only, not lab)
  5. AC750                   - Lab Management WiFi Access Point
  6. NAS FS6706T             - ASUSTOR FlashStor NFS Storage
  7. Prod Server             - Proxmox Production host (+ VMs / LXCs)
  8. Dev Server              - Proxmox Development host (+ VMs / LXCs)

================================================================================
                         PHYSICAL TOPOLOGY (CURRENT)
================================================================================

ISP ONT
 ├── MikroTik [ether1 - WAN/mgmt uplink] ───── Lab Network Gateway (10.0.5.1)
 │     │
 │     │  NOTE: service VLAN trunks for both envs go DIRECTLY from each
 │     │        Proxmox host's svc0 into a dedicated MikroTik port. They
 │     │        no longer go through the FS308GP switch. See the "Why
 │     │        bypass the switch" section in network/README.md and
 │     │        TS-NET-003 (troubleshooting/network/) for the reason.
 │     │
 │     ├── ether5 ─── Prod Server svc0 (DIRECT, 100M forced) ─ VLANs 50-55 trunk
 │     │
 │     ├── ether6 ─── Dev Server svc0 (DIRECT, 100M forced) ─ VLANs 60-65 trunk
 │     │                   (bridge br-dev on MikroTik)
 │     │
 │     └── ether7 ─── AC750 AP (VLAN 5 untagged — mgmt plane)
 │                       ├── NAS Mgmt Port (downlink, VLAN 5)
 │                       └── WiFi SSID: unified_mgmt (AP Isolation enabled)
 │                           ├── Prod Server (wlp4s0)  10.0.5.100
 │                           └── Dev Server  (wlp1s0)  10.0.5.110
 │
 ├── FS308GP [Port 1 direct to ISP for Festa Cloud mgmt] (Mgmt IP 192.168.100.185)
 │     │
 │     │  Switch now carries ONLY the storage VLAN. Service-VLAN trunks
 │     │  that used to ride on Ports 2-5 are gone — those ports are unused.
 │     │  See switch/fs308gp/config.txt for current vs historical layout.
 │     │
 │     └── VLAN 40 (Storage, tagged, L2-isolated)
 │           ├── Port 6 ─── NAS (LAN 1)         10.0.40.120
 │           ├── Port 7 ─── Dev Proxmox (stor0) 10.0.40.110
 │           └── Port 8 ─── Prod Proxmox (stor0) 10.0.40.100
 │
 │           Each Proxmox in turn provides VLAN 40 via stor0 to its
 │           k8s worker VMs, so each worker has a second NIC on VLAN 40
 │           for CSI-NFS PersistentVolume access:
 │
 │             Prod workers:  10.0.40.101 / .102 / .103
 │             Dev  workers:  10.0.40.201 / .202 / .203
 │
 └── AX3000 [WiFi AP Mode] ─────── Home devices only (phones, tablets, etc.)
       └── Isolated from lab entirely — goes straight to ISP

================================================================================
                         TRAFFIC FLOW
================================================================================

Lab Traffic:
 └── All lab service-VLAN traffic routes through MikroTik for firewall / ACL
     control (dev→prod isolation, env→AWS VPN, etc.)

Home Traffic:
 └── Home devices on AX3000 WiFi go directly to ISP (isolated from lab)

Storage Traffic:
 └── VLAN 40 is L2-isolated on the FS308GP switch — NO router hop.
     Proxmox hosts and k8s worker VMs talk to the NAS directly over L2
     on VLAN 40. This was intentional from day one and has stayed the same
     across both the ER605 era and the MikroTik era.
