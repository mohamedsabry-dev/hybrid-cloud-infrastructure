                              IP PLANNING

registered in IPA DNS. The current router is a MikroTik L009UiGS-RM (previously
a TP-Link ER605 — see /network/README.md for the migration story).

                         STORAGE PLANE (VLAN 40)
================================================================================

Device                  | IP Address    | Protocol / Purpose
------------------------|---------------|--------------------------------------------
Prod Proxmox host       | 10.0.40.100   | NFS client (storage interface, no hostname)
Prod K8s Worker 1       | 10.0.40.101   | NFS client — CSI-NFS for k8s PVs
Prod K8s Worker 2       | 10.0.40.102   | NFS client — CSI-NFS for k8s PVs
Prod K8s Worker 3       | 10.0.40.103   | NFS client — CSI-NFS for k8s PVs
Dev Proxmox host        | 10.0.40.110   | NFS client (storage interface, no hostname)
Dev K8s Worker 1        | 10.0.40.201   | NFS client — CSI-NFS for k8s PVs
Dev K8s Worker 2        | 10.0.40.202   | NFS client — CSI-NFS for k8s PVs
Dev K8s Worker 3        | 10.0.40.203   | NFS client — CSI-NFS for k8s PVs
NAS                     | 10.0.40.120   | NFS server (storage interface, no hostname)

Notes:
  - Storage traffic is L2-isolated on the FS308GP switch — it does NOT route
    through the router.
  - Proxmox hosts expose a stor0.40 tagged VLAN subinterface for NFS.
  - K8s worker VMs each have a SECOND NIC on VLAN 40 for CSI-NFS PV access.
  - Address range convention:
      .100-.103  -> Prod (host + 3 workers)
      .110       -> Dev Proxmox host
      .120       -> NAS
      .201-.203  -> Dev workers (separated from .101-.103 to avoid collision)
  - No DNS hostnames for storage-plane interfaces — IP only.
