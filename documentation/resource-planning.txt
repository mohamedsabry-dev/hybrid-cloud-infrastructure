├── Routing Design (Production Pattern)
│   │
│   ├── ER605 as central L3 router for ALL VLANs
│   │   ├── All inter-VLAN traffic passes through ER605
│   │   ├── Centralized firewall rules between VLANs
│   │   ├── Traffic inspection and logging
│   │   ├── Single point of policy enforcement
│   │   └── Matches production L3 switch pattern
│   │
│   ├── Why not Proxmox internal routing?
│   │   ├── No firewall between VLANs = security gap
│   │   ├── Production requires L3 device between layers
│   │   ├── Service layer should not reach Management directly
│   │   └── Audit trail requires centralized routing
│   │
│   └── Proxmox role
│       ├── L2 bridging only (VLAN tagging)
│       ├── No routing between VLANs
│       └── Trunk port to ER605 carries all VLANs
