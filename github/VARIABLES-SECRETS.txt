All sensitive data retrieved from AWS Secrets Manager at runtime via OIDC.

Why:
├── Secrets Manager provides audit trail (CloudTrail)
├── Centralized secret management
├── Easy rotation without updating GitHub
├── OIDC = no long-lived credentials stored

================================================================================
                         FETCHING SECRETS IN WORKFLOWS
================================================================================

Pattern: OIDC → Assume Role → Get Secret
─────────────────────────────────────────────────────────────────────────────────

```yaml
steps:
  - name: Configure AWS Credentials
    uses: aws-actions/configure-aws-credentials@v4
    with:
      role-to-assume: arn:aws:iam::${{ vars.AWS_ACCOUNT_ID_DEV }}:role/GitHubActions-Infrastructure-dev
      aws-region: ${{ vars.AWS_REGION }}

  - name: Get Proxmox Token
    id: secrets
    run: |
      SECRET=$(aws secretsmanager get-secret-value \
        --secret-id dev/proxmox/terraform-token \
        --query SecretString \
        --output text)

      TOKEN_ID=$(echo $SECRET | jq -r '.token_id')
      TOKEN_SECRET=$(echo $SECRET | jq -r '.token_secret')

      # Set as environment variable (masked in logs)
      echo "PROXMOX_VE_API_TOKEN=${TOKEN_ID}=${TOKEN_SECRET}" >> $GITHUB_ENV

      # Or set as output
      echo "token_id=${TOKEN_ID}" >> $GITHUB_OUTPUT
```
