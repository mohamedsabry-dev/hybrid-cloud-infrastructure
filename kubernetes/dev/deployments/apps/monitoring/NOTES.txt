MONITORING STACK - PRE-ACTIVATION CHECKLIST
===========================================

Before adding resources to kustomization.yaml, complete the following:


1. VAULT SETUP
--------------
Run these on the Vault cluster:

  vault kv put secret/grafana/config \
    admin_user=admin \
    admin_password=<your-password>

  vault policy write grafana - <<EOF
  path "secret/data/grafana/config" {
    capabilities = ["read"]
  }
  EOF

  vault write auth/kubernetes/role/grafana \
    bound_service_account_names=grafana-sa \
    bound_service_account_namespaces=monitoring \
    policies=grafana \
    ttl=1h


2. NODE EXPORTER — EXTERNAL HOSTS
----------------------------------
Install node_exporter on each of the following (port 9100):

  10.0.60.10  freeipa.lab.local
  10.0.62.10  vault1.lab.local
  10.0.62.11  vault2.lab.local
  10.0.62.12  vault3.lab.local
  10.0.63.10  ansible.lab.local
  10.0.63.20  local-runner.lab.local
  10.0.65.10  ex-nginx.lab.local

  Install (Debian/Ubuntu):
    apt install prometheus-node-exporter
    systemctl enable --now prometheus-node-exporter

  Install (RHEL/Rocky):
    # Download from https://github.com/prometheus/node_exporter/releases
    # Or use the ansible playbook if available

  Note: k8s-master1/2/3 and k8s-worker1/2/3 are excluded —
        node-exporter DaemonSet covers them automatically.


3. ACTIVATE
-----------
Once the above is done, update kustomization.yaml to:

  resources:
    - vault-ca-secret.yaml
    - service-account.yaml
    - helm-release.yaml


4. VERIFY AFTER DEPLOY
-----------------------
  kubectl get helmrelease -n monitoring
  kubectl get pods -n monitoring
  # Grafana UI: http://grafana-dev.lab.local:30080
