# Cloud Backup

> **Backup replication to cloud storage**

## Overview

This folder contains documentation for replicating backups to cloud storage providers (AWS S3, Azure Blob, GCP Cloud Storage) for offsite protection.

- Cost optimization

### Recovery from Cloud

- Recovery time objectives (RTO)
- Data transfer considerations
