# Secrets Management

> **Centralized secrets and credential management**

## Overview

This folder contains documentation for secrets management services that provide secure storage, access control, and rotation of credentials, API keys, and sensitive data.

---

## Services Covered

### HashiCorp Vault
- 3-node HA cluster configuration
- Secrets storage and retrieval
- Dynamic credentials
- Encryption as a Service
- PKI/Certificate management
- Auto-unseal configuration
