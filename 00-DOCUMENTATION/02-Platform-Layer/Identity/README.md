# Identity Management

> **Centralized identity and access management services**

## Overview

This folder contains documentation for identity and access management services that provide authentication, authorization, and directory services for the entire DC-K8s environment.

---

## Services Covered

### FreeIPA
- User and group management
- Kerberos authentication (SSO)
- LDAP directory services
- Host-Based Access Control (HBAC)
- Sudo rules management
- DNS integration
