SCENARIO: new critical pod needs scheduling,
          nodes at 90% usage
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

kubectl apply / Flux pushes deployment
  └─► kube-apiserver saves pod to etcd
        └─► scheduler notified → tries to place critical pod
              └─► filtering stage
                    ├── node-1: not enough memory → filtered out
                    ├── node-2: not enough memory → filtered out
                    └─► no eligible node found
                          └─► preemption controller kicks in (inside scheduler)
                                └─► scans running pods across all nodes
                                      └─► finds minor pods running on node-1
                                            └─► evicts minor pod to free space
                                                  └─► minor pod status → Terminating
                                                        └─► node-1 has space now
                                                              └─► scoring stage
                                                                    └─► node-1 wins
                                                                          └─► critical pod scheduled ✅
                                                                                └─► kubelet on node-1
                                                                                      └─► pulls image
                                                                                            └─► starts container
                                                                                                  └─► pod Running ✅

SCENARIO: node memory spikes while pods running
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

pods running normally on node-1
  └─► actual memory usage climbs
        ├── hits evictionSoft threshold (200Mi remaining)
        │     └─► kubelet waits grace period (1m30s)
        │           └─► usage still high after grace period
        │                 └─► kubelet evicts lowest priority pod first
        │                       └─► minor pod → Terminating
        │                             └─► memory freed ✅
        │
        └── spikes past evictionHard threshold (100Mi remaining)
              └─► kubelet evicts immediately, no grace period
                    └─► minor pod → Terminating instantly
                          ├── memory freed → node stable ✅
                          └─► if usage still climbing after eviction
                                └─► Linux kernel OOM killer activates
                                      └─► kills highest memory process directly
                                            └─► container dies → pod restarts ❌
                                                  └─► outside Kubernetes control

SCENARIO: evicted minor pod tries to come back
          via HPA, but no space
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

minor pod evicted → Terminating
  └─► HPA sees load still high
        └─► HPA creates new minor pod
              └─► scheduler tries to place it
                    └─► filtering → no space on any node
                          └─► no lower priority pods to evict
                                └─► minor pod stays Pending ⏳
                                      └─► HPA keeps wanting it
                                            └─► stays Pending until:
                                                  ├── critical pod finishes → frees space
                                                  ├── new node joins cluster
                                                  └─► actual load drops → HPA scales down

SCENARIO: node goes down
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

node-1 goes down
  └─► kube-controller-manager detects no heartbeat
        └─► after 5 minutes marks all node-1 pods Terminating
              └─► scheduler tries to reschedule on remaining nodes
                    ├─► critical pods
                    │     └─► preemption evicts lower priority if needed ✅
                    │           └─► rescheduled on node-2 or node-3 ✅
                    ├─► major pods
                    │     └─► preemption evicts minor if needed ✅
                    │           └─► rescheduled ✅
                    └─► minor pods
                          └─► no space, nothing lower to evict
                                └─► stays Pending ⏳
