================================================================================
SRE-8 Phase 2 - Setup Proxmox Server & Infrastructure Foundation
================================================================================

## Description

Phase 2 focuses on setting up the Proxmox physical host, configuring the
foundational infrastructure services (Zone C - Master Infrastructure), and
establishing the AWS IAM / CI/CD pipelines that support Terraform-driven
provisioning.

Key decision: Migrated from Proxmox 8.4 to 9.1 for container improvements,
Terraform provider compatibility, and better performance. Shutdown the old
environment completely and started fresh on a dedicated NVMe 2TB drive
(dual-boot beside Windows, not on top of it). Boot issue on 8.4 was resolved
by disabling the GPU before migration.
