                         GITHUB WORKFLOWS

Workflow Files
─────────────────────────────────────────────────────────────────────────────────
Workflow                │ Purpose                  │ Trigger                    │ Runner
────────────────────────┼──────────────────────────┼────────────────────────────┼───────────
tf-bootstrap.yml        │ Terraform Apply (Audit)  │ push + workflow_dispatch   │ production
setup-providers.yml     │ Provider Mirror Setup    │ push + workflow_dispatch   │ production

Workflow Details:
├── tf-bootstrap.yml: Deploys CloudTrail via Terraform, uses GitHubActions-Audit role
│   ├── Push trigger: auto-runs on feature branch (for testing)
│   ├── workflow_dispatch: manual trigger, requires typing "deploy" to confirm
│   └── Path filter: only runs when workflow or terraform files change
└── setup-providers.yml: Downloads providers to local mirror, configures ~/.terraformrc

================================================================================
                         ISSUES & LESSONS LEARNED
================================================================================

─────────────────────────────────────────────────────────────────────────────────
Issue                                        │ Resolution
─────────────────────────────────────────────┼─────────────────────────────────
CloudFormation resource recreation           │ Don't change Description/Name (immutable)
GitSync auto-deploy security risk            │ Branch protection + CODEOWNERS
Provider download slow on runner             │ Created local provider mirror
ReadOnly role redundant                      │ Deleted - all roles have ReadOnlyAccess
PassRole too permissive (Resource: *)        │ Limited to EC2-* and EKS-* role patterns
Network/App policy overlap                   │ Separated: Network=fabric, App=compute
S3 bucket missing SSL enforcement            │ Added DenyNonSSL statement to policies
DynamoDB missing deletion protection         │ Added DeletionProtectionEnabled + SSE
