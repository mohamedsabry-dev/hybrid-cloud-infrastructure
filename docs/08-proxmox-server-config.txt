================================================================================
                         SETUP WORKFLOW
================================================================================

STEP 0: INTERFACE NAMING
─────────────────────────────────────────────────────────────────────────────────
Standard interface names (rename via systemd .link files):

Original Name      │ Standard Name │ Purpose
───────────────────┼───────────────┼──────────────────────
wlp1s0 / wlp4s0    │ (keep orig)   │ Management WiFi
nic0 (varies)      │ svc0          │ Service VLAN trunk
enxc8a362d2713e    │ stor0         │ Storage network

NOTE: WiFi interface renaming (wifi0) did not work reliably during testing.
The .link file was created but the name reverted after reboot.
Keep original WiFi name in scripts. Only rename svc0 and stor0.

Create .link files in /etc/systemd/network/:

```bash
# Service interface (get MAC with: ip link)
cat > /etc/systemd/network/10-svc0.link << 'EOF'
[Match]
MACAddress=XX:XX:XX:XX:XX:XX

[Link]
Name=svc0
EOF

# Storage interface
cat > /etc/systemd/network/10-stor0.link << 'EOF'
[Match]
MACAddress=XX:XX:XX:XX:XX:XX

[Link]
Name=stor0
EOF
```

Reboot after creating .link files.

================================================================================
STEP 1: BOOTSTRAP (Run First)
================================================================================

Script: foundation/proxmox/bootstrap-dev.sh

Purpose:
├── Disable sleep/suspend
├── Fix APT repos (disable enterprise, enable no-subscription)
├── APT update/upgrade
├── Remove subscription nag popup
└── Create admin user

Run from temporary IP (192.168.0.x):
```bash
scp bootstrap-dev.sh root@192.168.0.x:/tmp/
ssh root@192.168.0.x
chmod +x /tmp/bootstrap-dev.sh
/tmp/bootstrap-dev.sh
```

================================================================================
STEP 2: NETWORK SETUP (Run Second)
================================================================================

Script: proxmox-network-setup-dev.sh (or -prod.sh)

Purpose:
├── Install wpasupplicant
├── Configure WiFi for management (10.0.5.x)
├── Configure vmbr0 as VLAN-aware bridge
└── Configure storage interface (10.0.40.x)

Prerequisites:
├── Interfaces svc0 and stor0 renamed (Step 0)
└── Bootstrap completed (Step 1)

Run from console (NOT over WiFi!):
```bash
scp proxmox-network-setup-dev.sh root@192.168.0.x:/tmp/
# Connect via console
chmod +x /tmp/proxmox-network-setup-dev.sh
WIFI_PASSWORD="yourpassword" /tmp/proxmox-network-setup-dev.sh
# Or without env var to be prompted for password
```

================================================================================
                         MANUAL CONFIGURATION STEPS
================================================================================

If not using scripts, follow these manual steps:

Step 1: Install WiFi packages
─────────────────────────────────────────────────────────────────────────────────
```bash
apt update && apt install -y wpasupplicant wireless-tools
```

Step 2: Create wpa_supplicant config
─────────────────────────────────────────────────────────────────────────────────
```bash
cat > /etc/wpa_supplicant/wpa_supplicant-wlp1s0.conf << 'EOF'
ctrl_interface=/var/run/wpa_supplicant
update_config=1
country=US

network={
    ssid="unified_mgmt"
    psk="##############"
    key_mgmt=WPA-PSK
}
EOF
chmod 600 /etc/wpa_supplicant/wpa_supplicant-wlp1s0.conf
```

Step 3: Test WiFi connection manually
─────────────────────────────────────────────────────────────────────────────────
```bash
wpa_supplicant -B -i wlp1s0 -c /etc/wpa_supplicant/wpa_supplicant-wlp1s0.conf
ip link set wlp1s0 up
ip addr add 10.0.5.110/24 dev wlp1s0
ping 10.0.5.1   # Test gateway
```

Step 4: Configure /etc/network/interfaces
─────────────────────────────────────────────────────────────────────────────────

DEV Server (/etc/network/interfaces):
```
auto lo
iface lo inet loopback

# WiFi Management Interface
auto wlp1s0
iface wlp1s0 inet static
    address 10.0.5.110
    netmask 255.255.255.0
    gateway 10.0.5.1
    wpa-conf /etc/wpa_supplicant/wpa_supplicant-wlp1s0.conf

# Service VLAN Trunk (to ER605 Port 4)
auto svc0
iface svc0 inet manual

auto vmbr0
iface vmbr0 inet manual
    bridge-ports svc0
    bridge-stp off
    bridge-fd 0
    bridge-vlan-aware yes
    bridge-vids 60-65

# Storage Interface (to Dumb Switch)
auto stor0
iface stor0 inet static
    address 10.0.40.110
    netmask 255.255.255.0

source /etc/network/interfaces.d/*
```

PROD Server (/etc/network/interfaces):
```
auto lo
iface lo inet loopback

# WiFi Management Interface
auto wlp4s0
iface wlp4s0 inet static
    address 10.0.5.100
    netmask 255.255.255.0
    gateway 10.0.5.1
    wpa-conf /etc/wpa_supplicant/wpa_supplicant-wlp4s0.conf

# Service VLAN Trunk (to ER605 Port 5)
auto svc0
iface svc0 inet manual

auto vmbr0
iface vmbr0 inet manual
    bridge-ports svc0
    bridge-stp off
    bridge-fd 0
    bridge-vlan-aware yes
    bridge-vids 50-55

# Storage Interface (to Dumb Switch)
auto stor0
iface stor0 inet static
    address 10.0.40.100
    netmask 255.255.255.0

source /etc/network/interfaces.d/*
```

Step 5: Enable wpa_supplicant service
─────────────────────────────────────────────────────────────────────────────────
```bash
systemctl enable wpa_supplicant
reboot
```

================================================================================
                         VLAN-AWARE BRIDGE CONCEPT
================================================================================

What Proxmox Needs:
─────────────────────────────────────────────────────────────────────────────────
One VLAN-aware bridge, not separate bridges per VLAN.

Physical port (svc0) → carries all VLANs as trunk
                    ↓
              vmbr0 (VLAN-aware bridge)
                    ↓
        Each VM gets assigned VLAN tag directly

Option A: VLAN-aware bridge (RECOMMENDED)
├── Single bridge vmbr0 with VLAN aware enabled
├── Each VM gets assigned VLAN tag directly
└── Proxmox handles tagging automatically

Option B: Separate bridge per VLAN
├── vmbr51 (VLAN 51)
├── vmbr52 (VLAN 52)
├── vmbr53 (VLAN 53)
└── etc...

Option A is cleaner and what Proxmox recommends.

VM Network Assignment:
─────────────────────────────────────────────────────────────────────────────────
VM network interface → vmbr0 → VLAN tag: 51
VM network interface → vmbr0 → VLAN tag: 52

Proxmox tags the traffic automatically based on VM assignment.
No need to create separate interface per VLAN.

================================================================================
                         RELATED TROUBLESHOOTING
================================================================================

Common Issues:
─────────────────────────────────────────────────────────────────────────────────

1. SSH hangs from WAN to LAN
   See: troubleshooting/05-asymmetric-routing-ssh-wan-lan.md
   Cause: Old IP on vmbr0 causing asymmetric routing

2. Node rename breaks cluster
   See: troubleshooting/03-proxmox-node-rename.md
   Must stop pve-cluster BEFORE changing hostname

3. WiFi interface name changes after reboot
   Solution: Keep original name (wlp1s0/wlp4s0), don't rename
