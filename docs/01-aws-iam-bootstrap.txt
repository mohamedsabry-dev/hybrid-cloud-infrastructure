├── Terraform State Bucket: Logging to AuditBucket, Lifecycle (90 days for old versions)
├── DynamoDB: DeletionProtectionEnabled, SSESpecification enabled
├── AuditBucket: Lifecycle (365 days expiration, 90 days for old versions)
└── Resources 2, 3, 4 have DeletionPolicy: Retain (won't delete if stack deleted)

================================================================================
                         IAM POLICIES
================================================================================

CloudFormation Stack Policies
─────────────────────────────────────────────────────────────────────────────────
Policy Name                              │ Purpose
─────────────────────────────────────────┼─────────────────────────────────────────
HybridCloud-TerraformState-Common        │ S3 + DynamoDB access for Terraform state
HybridCloud-Terraform-SecurityBoundary   │ PassRole for EC2-*/EKS-* only, Deny IAM mutations
HybridCloud-NetworkFullManagement        │ Core network: VPC, Subnets, Routes, VPN, Peering, NACLs, Endpoints
HybridCloud-ApplicationFullManagement    │ App-facing: EC2, EKS, ECR, SG, NAT, ELB, EIP, ENI
HybridCloud-SecurityAuditControl         │ CloudTrail, CloudWatch, EventBridge, SNS, Audit Bucket config

Policy Details:
├── TerraformStatePolicy: Uses !ImportValue for bucket/table ARNs (cross-stack reference)
├── SecurityBoundary: PassRole limited to EC2-* and EKS-* role patterns only
├── NetworkFullManagement: Core fabric only (VPC, subnets, routes, VPN, peering)
├── ApplicationFullManagement: Includes SG, NAT, ELB, EIP, ENI (app-facing resources)
└── SecurityAuditControl: PassRole for CloudTrail role, manages audit infrastructure

Explicit Denies: IAM mutations, Billing, CloudTrail modifications
