================================================================================
                    STEP 6: MANUAL ANSIBLE ADMIN SETUP
================================================================================

SSH to Ansible LXC and configure for manual playbook execution:

    ssh root@ansible.lab.local
    # or: ssh root@10.0.63.10

    # 1. Set Ansible config path (add to bashrc for persistence)
    echo 'export ANSIBLE_CONFIG=/srv/repo/ansible/dev/ansible.cfg' >> ~/.bashrc
    source ~/.bashrc

    # 2. Create vault password file (get password from AWS or team)
    echo 'YOUR_VAULT_PASSWORD' > ~/.ansible_vault
    chmod 600 ~/.ansible_vault

    # 3. Create encrypted secrets (if not already done)
    # Bot user password:
    ansible-vault encrypt_string 'bot_password_here' --name 'default_bot_user_password'
    # Admin user password:
    ansible-vault encrypt_string 'admin_password_here' --name 'default_admin_user_password'
    # IPA admin password:
    ansible-vault encrypt_string 'ipa_admin_pass' --name 'ipaadmin_password'

    # 4. Get Kerberos ticket for Ansible operations
    kinit super_bot

    # 5. Verify connectivity
    ansible all -m ping


================================================================================
                      STEP 7: RUN ANSIBLE PLAYBOOKS
================================================================================

From Ansible LXC (/srv/repo/ansible/dev):

    cd /srv/repo/ansible/dev

    # --- Common Setup (all nodes) ---
    # Fix base OS issues, install packages, enable SSH password auth
    ansible-playbook -i inventory/inventory.ini playbooks/common/baseos_fix.yml
    ansible-playbook -i inventory/inventory.ini playbooks/common/initial_packages.yml
    ansible-playbook -i inventory/inventory.ini playbooks/common/enable_ssh_password_auth.yml

    # --- Join Hosts to FreeIPA Domain ---
    # Enrolls all managed_hosts as IPA clients
    ansible-playbook -i inventory/inventory.ini playbooks/freeipa/add_hosts_to_ipa.yml

    # --- Configure FreeIPA Domain Objects ---
    # Creates: host groups, users, sudo rules, HBAC rules, password policies
    ansible-playbook -i inventory/inventory.ini playbooks/freeipa/domain_config.yml

    # --- Fix LXC Kerberos Auth (if needed) ---
    # Fixes password auth on LXCs (keyring → file ccache)
    ansible-playbook -i inventory/inventory.ini playbooks/freeipa/fix_lxc_krb5_keyring.yml
