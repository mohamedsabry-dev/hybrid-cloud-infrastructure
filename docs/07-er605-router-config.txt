================================================================================
                         MAC MINI STATIC ROUTE
================================================================================

Static Route (on Mac Mini, not ER605)
─────────────────────────────────────────────────────────────────────────────────
Allows Mac Mini (192.168.0.223) to reach all 10.x internal networks via ER605.

Manual command:
```bash
sudo route add -net 10.0.0.0/8 192.168.0.175
```

Persistent installation (survives reboot):
```bash
cd foundation/mac-mini
sudo ./install-route.sh
```

Files installed:
├── /usr/local/bin/add-route.sh                    (waits for network, adds route)
└── /Library/LaunchDaemons/com.local.route10.plist (runs at boot)

Verify after reboot:
```bash
netstat -rn | grep "^10"
# Should show: 10/8  192.168.0.175  UGSc  ...
```

================================================================================
                         CONFIGURATION WORKFLOW
================================================================================

KEY DISCOVERY - Correct Configuration Sequence:
─────────────────────────────────────────────────────────────────────────────────

1. Create LAN Interface (Network → LAN → Add)
   ├── Set Name, VLAN ID, IP, Subnet Mask
   └── VLAN auto-creates with same ID

2. Edit VLAN (Network → VLAN → Edit)
   ├── Change ports from "all" to specific port
   └── Set TAG mode for trunk ports

3. Create IP Address Lists (Preferences → IP Group → IP Address)
   ├── One list per subnet (granular approach)
   └── Enables reuse in multiple rules

4. Create IP Groups (Preferences → IP Group → IP Group)
   ├── Combine lists into logical groups
   └── Use for broad ACL rules

5. Create ACL Rules (Firewall → Access Control)
   ├── Use Direction "All" to access IP Groups
   └── Direction "LAN→LAN" only shows LAN names
