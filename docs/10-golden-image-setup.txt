================================================================================
                    GOLDEN IMAGE SETUP GUIDE
                    Rocky Linux 10.1 on Proxmox
================================================================================

OVERVIEW
--------
This guide documents creating a Rocky Linux 10.1 golden image template on
Proxmox for VM cloning. Used for K8s masters/workers, IPA, Vault nodes.

ISO: Rocky-10.1-x86_64-minimal.iso


================================================================================
WORKFLOW SUMMARY
================================================================================

1. Push to dev branch     → Triggers workflow, creates VM
2. Manual OS install      → Install Rocky Linux from ISO
3. Manual setup script    → Run golden-image-setup.sh, test, shutdown
4. Approve workflow gate  → Workflow removes CD-ROM, converts to template
5. Template ready         → Clone VMs from template


================================================================================
STEP 1: TRIGGER WORKFLOW
================================================================================

Push changes to dev branch or manually trigger workflow:

    gh workflow run "Dev - Proxmox Golden Image" --ref dev -f action=apply

Workflow creates VM 9000 and waits at approval gate.


================================================================================
STEP 2: MANUAL OS INSTALLATION (IMPORTANT)
================================================================================

Open Proxmox console for VM 9000 and configure:

ROOT ACCOUNT
------------
  - Root Password       : Set strong password
  - Allow root SSH      : ENABLED (check this!)

STORAGE
-------
  - Installation Dest   : Use the 20GB disk (automatic partitioning)

SOFTWARE SELECTION
------------------
  - Base Environment    : Minimal Install
  - Additional Software : Standard (check this!)

NETWORK CONFIGURATION
---------------------
  - IP Address          : 10.0.65.99
  - Subnet Mask         : /24 (255.255.255.0)
  - Gateway             : 10.0.65.1
  - DNS Server          : 8.8.8.8
  - Search Domain       : lab.local

Click "Begin Installation" and wait for completion.

AFTER INSTALLATION - REBOOT
---------------------------
When installation completes and prompts to restart:
  1. Click "Reboot System"
  2. VM will boot to ISO menu again (CD-ROM is first in boot order)
  3. Select "Troubleshooting" from the menu
  4. Select "Boot from local drive"
  5. VM boots from installed disk


================================================================================
STEP 3: RUN SETUP SCRIPT
================================================================================

After installation completes and VM reboots:

1. Copy script to VM:

    scp infrastructure/compute/golden-image-setup.sh root@10.0.65.99:/tmp/

2. SSH and run script:

    ssh root@10.0.65.99
    chmod +x /tmp/golden-image-setup.sh
    /tmp/golden-image-setup.sh

3. Script installs:
   - qemu-guest-agent, cloud-init
   - vim, htop, git, jq, curl, wget
   - net-tools, traceroute, bind-utils, nmcli, tcpdump
   - ipa-client (package only)
   - gandalf user (break-glass, locked)

4. FOR DEV ENVIRONMENT:
   - When prompted "Proceed with cleanup and shutdown?" → Answer "n"
   - Review and test manually
   - Verify: rpm -q qemu-guest-agent cloud-init ipa-client
   - When satisfied, run script again → Answer "y"
   - VM will cleanup and shutdown


================================================================================
STEP 4: APPROVE WORKFLOW GATE
================================================================================

After VM is shutdown:

1. Go to GitHub Actions
2. Find the running "Dev - Proxmox Golden Image" workflow
3. Click "Review deployments"
4. Approve the "golden-image-approval" environment

Workflow automatically:
  - Verifies VM is stopped
  - Removes CD-ROM drive
  - Updates boot order to disk only (scsi0)
  - Converts VM to template


================================================================================
STEP 5: VERIFY TEMPLATE
================================================================================

In Proxmox UI:
  - VM 9000 should show as template (icon changes)
  - Cannot start a template directly
  - Clone to create new VMs

================================================================================
TROUBLESHOOTING
================================================================================

See: troubleshooting/06-proxmox-golden-image-terraform.md

1. Terraform stuck at "Refreshing state"
   - VM has agent enabled but not responding
   - Solution: qm stop 9000 --skiplock && qm destroy 9000 --purge

2. State lock error in DynamoDB
   - Previous run left lock
   - Solution: AWS Console > DynamoDB > Tables >
     hybrid-cloud-infrastructure-tf-state-lock-dev > Delete lock item

3. Workflow waiting forever
   - Need GitHub environment "golden-image-approval"
   - Create: Settings > Environments > New > Add yourself as reviewer

4. agent { enabled = true } causes Terraform to wait
   - This is normal - waits for qemu-guest-agent to respond
   - Agent installed by setup script
