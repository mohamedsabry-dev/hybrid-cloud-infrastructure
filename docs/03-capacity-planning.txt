Key Points:
├── GitHub = source of truth for code
├── GitHub Actions = CI (build, test)
├── Self-hosted runner = internal network access + Vault secrets
├── ArgoCD = CD (GitOps deployment to K8s)
└── Secrets: AWS Secrets Manager (cloud) / Vault (internal)

│
├── CI/CD Stack:
│   ├── GitHub Actions: CI pipelines
│   ├── GH Runner (self-hosted): Internal builds with Vault access
│   └── ArgoCD: GitOps CD (auto-deploy to K8s from Git)
│
└── GitOps Flow:
    Push code → GitHub Actions → GH Runner (build/test)
              → Update manifests → ArgoCD → Kubernetes
