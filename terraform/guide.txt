Terraform Commands Quick Reference
===================================

cd /Users/sabry/WorkSpace/hybrid-cloud-infrastructure/terraform/dev/aws/
AWS_PROFILE=plan-cross-dev terraform init
AWS_PROFILE=plan-cross-dev terraform plan

cd /Users/sabry/WorkSpace/hybrid-cloud-infrastructure/terraform/prod/aws/
AWS_PROFILE=prod-readonly terraform init
AWS_PROFILE=prod-readonly terraform plan -lock=false

# Local plan: override to use read-only token                                                                
AWS_PROFILE=prod-readonly TF_VAR_proxmox_secret_id=prod/proxmox/plan-readonly-token terraform plan -lock=false

AWS PROFILES
------------
plan-cross-dev   -> Dev account (REDACTED_AWS_DEV) - direct credentials
prod-readonly    -> Prod account (REDACTED_AWS_PROD) - assumes CrossAccount-ReadOnly-prod role
