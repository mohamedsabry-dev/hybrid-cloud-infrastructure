Terraform Commands Quick Reference
===================================

DEV MODULES (terraform/dev/*)
-----------------------------
# Plan
AWS_PROFILE=plan-cross-dev terraform plan

# Apply
AWS_PROFILE=plan-cross-dev terraform apply


PROD MODULES (terraform/prod/*)
-------------------------------
# Plan (read-only, no state lock needed)
AWS_PROFILE=prod-readonly terraform plan -lock=false

# Apply (use CI/CD only - push to main branch)
# Do NOT apply prod locally - use GitHub Actions workflow


AWS PROFILES
------------
plan-cross-dev   -> Dev account (REDACTED_AWS_DEV) - direct credentials
prod-readonly    -> Prod account (REDACTED_AWS_PROD) - assumes CrossAccount-ReadOnly-prod role


NOTES
-----
- prod-readonly is READ-ONLY, cannot apply changes
- All prod changes go through GitHub Actions on main branch
- Use -lock=false for prod plan (ReadOnly can't acquire locks)
