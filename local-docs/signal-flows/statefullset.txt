DIFFERENT FROM DEPLOYMENT — pod identity:
  ├── pod name is STABLE: mariadb-0 (not random hash)
  ├── pod dies → recreated with SAME name: mariadb-0
  ├── serviceName: mariadb links StatefulSet to headless Service
  │     enables stable DNS per pod:
  │     mariadb-0.mariadb.database.svc.cluster.local
  │     useful if adding replication later (pods find each other by name)
  └── PVC survives pod deletion:
        mariadb-0 deleted → PVC mariadb-data-mariadb-0 stays
        mariadb-0 recreated → automatically reattaches to same PVC
        data preserved across pod restarts ✅

TWO SERVICES (different from Deployment which only needs one):
  ├── Headless Service (clusterIP: None) name: mariadb
  │     no load balancing — enables per-pod stable DNS
  │     StatefulSet requires this — linked via spec.serviceName
  └── ClusterIP Service name: mariadb-svc
        used by WordPress: mariadb-svc.database.svc.cluster.local
        load balances across healthy pods (readiness probe)
        same pattern as Deployment

DIFFERENT FROM DEPLOYMENT — rolling update:
  ├── pods updated in REVERSE order: last pod first, mariadb-0 last
  ├── each pod must be healthy before next is updated
  └── safer for databases — primary (mariadb-0) updated last

DIFFERENT FROM DEPLOYMENT — deletion behavior:
  ├── StatefulSet deleted → pods deleted in reverse order
  ├── PVCs NOT deleted → must delete manually
  │     kubectl delete pvc mariadb-data-mariadb-0 -n database
  └── volumeClaimTemplate immutable → must delete StatefulSet + PVC to change storageClass
        WARNING: always backup NAS data before this operation

PVC lifecycle:
  ├── PVC auto-created when pod scheduled (replicas > 0)
  ├── replicas: 0 → NO PVC created → must create manually if needed
  │     name must match formula exactly: mariadb-data-mariadb-0
  ├── PVC survives pod deletion and StatefulSet deletion
  └── reclaimPolicy: Retain → PV goes Released on PVC deletion → NAS untouched

volumes in final pod (yours + injector added):
  ├── mariadb-data → PVC mariadb-data-mariadb-0 (NFS hard mount, /var/lib/mysql)

  └── /vault/tls/ → Secret vault-ca (added by injector, ca.crt for TLS verification)
