How to use:
1. Pick a skill. Open its file.
2. Answer each question out loud — standard answer first.
3. Inject one project example as a 30-second bridge (bait the follow-up).
4. After finishing, review the coverage checklist — did you hit each point?
5. Mark gaps and drill them.

The original 400-question bank (interview-question-bank.md in technical-papers/)
is still the full reference. This version is the drill format.
