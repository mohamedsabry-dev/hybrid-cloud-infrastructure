DR UPS Monitor - Decision Making Guide
======================================

OVERVIEW
--------
Proxmox installed bare-metal on laptop uses the laptop battery as a UPS.
This script detects power outages and triggers safe shutdown before battery dies.


HOW TO DETECT BATTERY STATUS
----------------------------
Linux exposes battery info at:
  /sys/class/power_supply/BAT0/status    → Charging, Discharging, Full
  /sys/class/power_supply/BAT0/capacity  → 0-100 (percentage)


KEY DECISION: DISCHARGING CHECK
-------------------------------
Only trigger shutdown if battery is DISCHARGING (going down).
If battery is "Charging" at 40%, power is BACK - don't shutdown!

Example:
  - Discharging at 50% → Power lost, consider shutdown
  - Charging at 50%    → Power restored, do nothing


BATTERY THRESHOLDS
------------------
Level       Threshold   Action                  Reason
─────────────────────────────────────────────────────────────────
CRITICAL    < 35%       Force halt NOW          No time left, save disks
LOW         < 55%       Graceful shutdown       Power definitely lost
WARNING     < 78%       Check network first     Maybe just unplugged briefly
NORMAL      > 78%       Monitor only            Plenty of time


WHY 78% FOR NETWORK CHECK?
--------------------------
At 78%, battery has ~20% buffer before LOW threshold.
Enough time to:
  1. Ping network for 2 minutes
  2. Confirm full site outage (not just charger unplugged)
  3. Still shutdown gracefully if needed


NETWORK CHECK LOGIC
-------------------
When battery < 78% AND discharging:
  - Ping 3 hosts: 10.0.5.1 (gateway), 10.0.40.120 (local), 8.8.8.8 (internet)
  - Check every 10 seconds for 2 minutes (12 rounds)
  - If ANY host responds → Network up, maybe just unplugged charger
  - If ALL fail for 2 min → Full site power outage, trigger shutdown


WHY 3 DIFFERENT HOSTS?
----------------------
  10.0.5.1    → Local gateway (on same UPS/power as server?)
  10.0.40.120 → Another local device
  8.8.8.8     → Internet (confirms ISP/external is also down)

If all 3 are down, it's likely a complete power outage, not just one device.


SHUTDOWN COMMANDS
-----------------
  shutdown +1   → Graceful, waits 1 min, VMs shutdown first, then host
  shutdown -h   → Halt/force, cuts power quickly (emergency only)

Proxmox graceful shutdown triggers VM/CT shutdown sequence automatically.


LOCK FILE
---------
/tmp/dr_ups_monitor.lock prevents multiple script instances.
If script is in 2-min ping loop and cron triggers again, it skips.


CRON SCHEDULE
-------------
*/5 * * * * → Every 5 minutes
Cron service auto-starts on boot, no extra setup needed.


LOG FILE
--------
/var/log/dr_ups.log - all output with timestamps for investigation.


QUICK SETUP
-----------
1. scp dr_ups_monitor.sh root@proxmox:/root/scripts/
2. chmod +x /root/scripts/dr_ups_monitor.sh
3. (crontab -l 2>/dev/null; echo "*/5 * * * * /root/scripts/dr_ups_monitor.sh >> /var/log/dr_ups.log 2>&1") | crontab -
4. Test: /root/scripts/dr_ups_monitor.sh
