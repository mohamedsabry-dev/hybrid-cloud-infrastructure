Secrets Architecture — Homelab Infra
│
├── AWS Secrets Manager  ← "External Bootstrap & Break Glass"
│   │
│   │   Accessed by : Terraform, GitHub Actions
│   │   Managed by  : AWS IAM policies (least privilege per consumer)
│   │   Rotated by  : Manual / AWS rotation policy
│   │
│   ├── homelab/proxmox/api_token
│   ├── homelab/proxmox/default_root_password      ← golden image default
│   ├── homelab/proxmox/break_glass_password       ← emergency human access
│   ├── homelab/lxc/default_root_password          ← LXC template default
│   ├── homelab/ansible/ssh_public_key             ← injected at provision
│   └── homelab/aws/root_account_password          ← the safe within the safe
│
├── HashiCorp Vault  ← "Internal Runtime & Operations"
│   │
│   │   Accessed by : K8s pods, Ansible playbooks (post-bootstrap),
│   │                 internal services, operators
│   │   Managed by  : Vault policies per service/team
│   │   Rotated by  : Vault dynamic secrets where possible
│   │   Unsealed by : AWS KMS auto-unseal (no manual key needed)
│   │
│   ├── pki/
│   │   ├── internal_ca/
│   │   ├── k8s_certs/
│   │   └── service_certs/
│   │
│   ├── ipa/
│   │   ├── admin_password              ← migrated from Ansible Vault phase 2
│   │   ├── keytabs/
│   │   └── service_principals/
│   │
│   ├── k8s/
│   │   ├── etcd_encryption_key
│   │   ├── service_account_keys/
│   │   └── pod_secrets/
│   │
│   ├── infra/
│   │   ├── proxmox_rotated_password    ← after default is changed post-bootstrap
│   │   ├── vm_root_passwords/          ← post-bootstrap rotated
│   │   └── lxc_root_passwords/         ← post-bootstrap rotated
│   │
│   └── monitoring/
│       ├── grafana_admin_password
│       └── prometheus_remote_write_key
│
└── Ansible Vault  ← "Bootstrap Only — Transitional"
    │
    │   Accessed by : Ansible playbooks only
    │   Managed by  : ~/.ansible_vault on Ansible LXC
    │   Rotated by  : Manual
    │   Scope       : Only secrets needed before HashiCorp Vault is reachable
    │
    ├── Phase 1 (now)
    │   └── ipaadmin_password
    │
    └── Phase 2 (after HashiCorp Vault is live + AWS KMS auto-unseal)
        └── [empty — fully deprecated, no longer needed]



"Is this secret needed before HashiCorp Vault is reachable?"
│
├── Yes, AND it's external/cloud scoped   → AWS Secrets Manager
├── Yes, AND it's Ansible playbook scoped → Ansible Vault (transitional)
└── No, needed at runtime                 → HashiCorp Vault


HashiCorp Vault starts
        │
        └── Auto-unseal via AWS KMS
                │
                └── Vault serves secrets
                        │
                        ├── Ansible pulls via community.hashi_vault
                        ├── K8s pods pull via Vault Agent / CSI driver
                        └── Services pull via Vault API
